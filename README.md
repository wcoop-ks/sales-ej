# sales-ej

電子ジャーナル（EJ）ファイルを解析し、カテゴリ別の販売数・販売額を集計するツールです。
WCOOP向けに構築されており、メインレジ（XE-A207）とサブレジ（XE-A147）の両フォーマットに対応しています。

## 機能

- EJFILE.TXT（Shift-JIS）のアップロード・自動デコード（複数ファイルをまとめて読み込み可）
- メイン/サブレジの自動判定（`責任\d+` の有無による）
- 日付範囲指定での絞り込み（終了日はオプション、デフォルトは開始日と同日）
- カテゴリ別販売数・販売額の集計テーブル表示
- 現金・クレジット（サブレジは信用）別の入金合計表示
- 時間帯別分析（30分／1時間／2時間ごとの会計件数・カテゴリ別個数／金額）
- ジャーナル原文の表示
- 日付変更による再計算
- TXT / PDF / Excel 形式での出力（データ範囲選択可）
- 一部入金後に解除された会計（二重計上の可能性）の警告表示

## SDカードからのデータ取り出し方法

### メインレジ (XE-A207)

1. モード切替を押す
2. SDカードを選択
3. 書き込みのみを選択
4. 電子ジャーナルを選択
5. 実行を選択
6. 実行前の画面に戻ったらSDカードを取り出す

### サブレジ (XE-A147)

1. 通常通り締め作業（キーを精算に合わせ 現/預/替 を押す）を行う
2. 印字が終わったらSDカードを取り出す

### ファイルの場所

SDカード内の以下のパスにEJファイルが保存されています：

```
SHARP > ECRXXX10/15 > WCOOP > EJ > yymmdd-n > EJFILE.txt
```

## 複数ファイルの読み込み

1日の途中でSDカードに書き込んだ日は、ジャーナルが複数の EJFILE.TXT に分かれる。
複数ファイルをまとめて指定すると、1つのジャーナルとして集計する。指定の方法は3通り。

- 「フォルダを選択」で SDカードの `SHARP`・`ECRXXX10`・`ECRXXX15`・`EJ` のいずれかを選ぶ
- 同じフォルダをドロップゾーンにドラッグ&ドロップする
- EJFILE.TXT を複数選択する（従来どおり）

フォルダ指定では `EJ/日付-n/EJFILE.TXT` だけを拾い、`EJPRINT`（印刷用の写し）と `._` ファイルは除く。
`SHARP` ごと指定して `ECRXXX10`（メイン）と `ECRXXX15`（サブ）の両方があるときは、
分析するレジを選ぶ欄を表示する（既定はメイン）。

結合のしかた:

- 日付行ごとの取引ブロックに分け、「日時＋取引番号」が同じブロックは1つにまとめる
  - サブレジ（書き込みとクリア）はファイル同士が重ならない
  - メインレジ（書込のみ）は後のファイルが前のファイルの内容を含むため、重なりをここで除く
- ファイルは先頭ブロックの日時が早い順につなげる（選択した順番は問わない）
- 内容から判定してメインレジとサブレジのファイルが混在しているときはエラーにする
- 読み込んだジャーナルは日付変更の再計算のためメモリー上に保持する（何か月分も読むと localStorage に入りきらないため）

サブレジの電子ジャーナルはレジ本体に約3,000行までしか残らず、メモリーフル時の動作が
「継続する」だと古い記録から消える。売上の多い日は途中で「電子ジャーナルの書き込みとクリア」を
おこない、その日のファイルをまとめて読み込む。

## レジ判定ロジック

ファイル内に `責任\d+`（例: `責任01`）が含まれる場合はメインレジ、含まれない場合はサブレジとして処理します。

## パーサの違い

| | メインレジ (XE-A207) | サブレジ (XE-A147) |
|---|---|---|
| 方式 | pending record方式 + トランザクションスナップショット | トランザクションバッファ方式 |
| 解除機能により中止 | 入金なし（合計¥0）はトランザクション開始時点にロールバック（取り消し）。一部入金後の解除（残額自動補填）はロールバックせずレジ日計どおり計上し警告表示 | トランザクション全体を破棄 |
| 訂正 | `内戻-` / `内訂-` / `訂 -` | `取引後訂正` でトランザクション全品マイナス計上 |
| 倍数戻品 | `66x -2` + `内戻-132` → 数量-2として計上 | — |

## 一部入金後解除トランザクションについて

XE-A207の仕様として、一部入金後に解除機能を使用するとレジは残額も自動補填して会計完了扱いにします。
レジ日計にはこの会計が売上・入金として計上されますが、実際には商品が売れておらず二重計上となる可能性があります。

この会計に対する担当者の対応（仕様を理解して手動で戻品し訂正する／何もしない／二重計上後にあえて販売登録せず実態をレジ状態に合わせる 等）は多様で、ツール側で実態を自動判定することはできません。そのため本ツールはこの会計を**取り消さず、レジ日計どおりに計上**したうえで、二重計上の**可能性**を警告として表示します。

警告には該当会計の **会計番号・金額・分類・単価・個数** を表示するので、必要に応じて手動で確認・調整してください。

### 訂正ヒント

実データでは、担当者が後で戻品（`戻-`）して打ち消しているケースが多い（2026年4〜6月の10件中9件）。
警告の「訂正」欄に、打ち消した戻品の手がかりを表示する。集計値は動かさない。

- 同じ日のそれ以降にある戻品を時刻順に見て、それより前の **同じ分類・同じ単価** の解除会計に、直前のものから順に個数を割り当てる
  - `60x -4` + `文具 内 戻-240` のようにまとめて戻品した場合も、複数の解除会計に1個ずつ割り当てる
  - 単価まで一致を求めるのは、別の打ち間違い（31,150円と3,150円など）を戻した高額の戻品を誤って当てないため
- 表示は「戻品で訂正済みの可能性」「一部のみ戻品あり」「訂正なし」の3種類。通常の返品が当たることもあるので目安として扱う
- 「訂正なし」の会計は、レジ日計でも二重計上のままで、締めで現金不足として出るなお、入金を伴わない通常の解除（合計¥0）は従来どおり集計から除外します。
